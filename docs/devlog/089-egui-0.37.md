# egui / eframe / egui_extras 0.33 → 0.37

**Status:** In progress
**Branch:** `chore/egui-0.37`
**Date:** 2026-11-13

## Why

- egui ≥ 0.35 shapes text with harfrust: Arabic joining and Indic shaping (#108).
- epaint 0.37 rasterizes color glyphs itself (`color_fonts`: COLR, sbix, CBDT,
  EBDT), replacing the swash path of our vendored epaint 0.33.3.
- eframe 0.37 disables the blocking swap on Wayland itself (egui#5136), the
  same fix as our `wayland_session` workaround (devlog 073).

## Plan

1. Manifests: egui/eframe/egui_extras 0.37, `rust-version` 1.95, renderer
   toolchain 1.95.0, eframe `clipboard` + `links` (opt-in since 0.37), epaint
   `color_fonts`.
2. epaint: vendor stock 0.37.0, then a small patch so face resolution honors
   U+FE0F / U+FE0E (0.37 resolves a cluster by its first char only).
3. Renderer port.
4. App port.
5. Docs.
